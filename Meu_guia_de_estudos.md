# Guia de Estudos

Este guia reúne recursos e uma sequência prática para estudar programação sem transformar o repositório em uma coleção infinita de links nunca revisitados.

## Ordem recomendada

1. **Lógica de programação**
2. **Python ou JavaScript para fundamentos**
3. **Shell para automação de ambiente**
4. **TypeScript para tipagem e aplicações maiores**
5. **Go para ferramentas compiladas, concorrência e serviços**
6. **Testes, Git, CI e projetos completos**

## Método

Para cada assunto:

1. Leia ou assista uma explicação curta.
2. Reescreva o conceito sem copiar.
3. Faça 3 exercícios pequenos.
4. Construa 1 script útil.
5. Registre o que aprendeu no README da linguagem.
6. Só avance quando conseguir explicar o código que escreveu.

A trilha completa está em [docs/ROADMAP.md](./docs/ROADMAP.md).
