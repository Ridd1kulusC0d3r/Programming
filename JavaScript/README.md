# JavaScript

This track covers modern JavaScript before frameworks are introduced. The point is to understand the language rather than collect dependencies.

## Track

1. Values, variables and operators
2. Functions and scope
3. Arrays and objects
4. Iteration methods
5. Modules
6. Errors
7. Promises and async/await
8. Files and runtime APIs with Node.js
9. HTTP requests
10. Small CLI and web projects

## Run

```bash
cd JavaScript
npm run start
npm run check
```
