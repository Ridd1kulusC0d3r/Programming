# Go

Go is used here for small command-line tools, concurrency exercises and networking-oriented software engineering fundamentals.

## Track

1. Packages, variables and functions
2. Structs, methods and interfaces
3. Errors and explicit error handling
4. Slices, maps and generics
5. Goroutines and channels
6. Context and cancellation
7. Files and JSON
8. HTTP clients and servers
9. Testing and benchmarks
10. CLI tools

## Run

```bash
cd Go
go run ./hello
go test ./...
```

## Project ladder

- CLI argument parser
- JSON transformer
- Concurrent URL status checker
- Log analyzer
- Small REST API
