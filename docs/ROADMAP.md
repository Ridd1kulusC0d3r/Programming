# Programming Roadmap

This roadmap turns the repository into a progressive learning system rather than a storage locker for abandoned snippets.

## Phase 1: Foundations

Use **Python + JavaScript** to learn universal concepts:

- variables and data types
- conditionals and loops
- functions
- collections
- input/output
- errors
- decomposition

**Deliverable:** 20 small exercises per language.

## Phase 2: Automation

Use **Python + Shell**:

- filesystem operations
- CSV/JSON processing
- subprocesses
- HTTP requests
- logging
- configuration
- CLI arguments

**Deliverable:** 5 useful automation scripts.

## Phase 3: Software engineering

Across all languages:

- modules and packages
- testing
- formatting/linting
- documentation
- Git branches and pull requests
- CI
- debugging

**Deliverable:** one tested mini-project per language.

## Phase 4: Typed and compiled development

Use **TypeScript + Go**:

- static typing
- interfaces/contracts
- error design
- concurrency
- build systems
- dependency management

**Deliverable:** one CLI in Go and one Node.js app in TypeScript.

## Phase 5: Portfolio

Build projects that solve real problems.

| Project | Primary language | Skills |
|---|---|---|
| Structured log analyzer | Python | parsing, CLI, reporting |
| Concurrent endpoint checker | Go | concurrency, HTTP, testing |
| Investigation notes parser | TypeScript | typed models, validation |
| Data normalization utility | JavaScript | transformations, Node APIs |
| Linux collection helper | Shell | processes, filesystem, defensive scripting |

Every portfolio project should include a README, usage examples, tests where appropriate, and a clear explanation of design decisions.
