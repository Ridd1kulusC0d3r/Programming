# Shell

The Shell track focuses on reliable Linux automation, command composition and operational scripting.

## Track

1. Shell execution model
2. Variables, quoting and expansion
3. Pipes and redirection
4. Exit codes
5. Functions and arguments
6. Filesystem automation
7. `grep`, `sed`, `awk` and `find`
8. Process inspection
9. Defensive scripting with `set -euo pipefail`
10. Reusable operational scripts

## Run

```bash
bash Shell/scripts/system-info.sh
```

Prefer readable scripts over compressed one-liners.
