# TypeScript

TypeScript is the typed application track of the repository. The emphasis is on modeling data correctly, writing maintainable modules and understanding the JavaScript runtime underneath the type system.

## Track

1. JavaScript foundations
2. Primitive and structural types
3. Functions and generics
4. Interfaces and type aliases
5. Narrowing and discriminated unions
6. Modules
7. Async programming
8. Validation and external data
9. Testing
10. Node.js applications

## Run

```bash
cd TypeScript
npm install
npm run check
npm run dev
```
