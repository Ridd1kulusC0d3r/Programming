# Python

Python is the most mature area of this repository and currently contains legacy study material, exercises and small scripts.

## Current content

- `Cursos/`: course exercises and experiments.
- `Códigos/`: loose code samples.
- `Scripts-produtivos/`: practical scripting experiments.
- `zen_of_python.py`: language notes/example.

## Recommended progression

1. Syntax and core types
2. Control flow and functions
3. Collections and comprehensions
4. Files, JSON and CSV
5. Exceptions and logging
6. Modules, packages and virtual environments
7. HTTP APIs
8. Testing with `pytest`
9. CLI applications
10. Data processing and automation

## Future organization

New Python work should gradually use:

```text
Python/
├── fundamentals/
├── exercises/
├── scripts/
├── projects/
└── README.md
```

The existing folders are intentionally preserved so historical learning material is not destroyed merely to satisfy aesthetics.
